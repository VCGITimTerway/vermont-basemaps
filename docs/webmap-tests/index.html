Web Map Examples

Named ArcGIS Online web maps built to test basemap appearance, each embedded live below. These are preconfigured examples for seeing how the basemaps look and function — not what to build against directly; use the Group Layers above for that. Full documentation (layers shown, design decisions) for each is linked alongside it. Thumbnails are each item's live ArcGIS Online thumbnail, not a static copy.

Test 02b is the current reference example for the Base Topo + Boundaries + Labels combination above.
