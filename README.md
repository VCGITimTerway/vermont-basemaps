# Vermont Basemaps
This is a repository for developing and maintaining updates to Vermont basemaps. Basemaps are being tested for use in ESRI and non-ESRI / open-source applications and environments.

## Test Version Previews
Development test versions of updated basemaps [are available here](https://vcgitimterway.github.io/vermont-basemaps/webmap-tests/). See links there for further documentation of them within this repo.
